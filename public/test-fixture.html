Brainwires OPFS — test fixture

This page seeds the Origin Private File System for this origin with a variety of files so you can exercise the DevTools panel. Open this page in a normal tab, click Seed OPFS, then open DevTools and switch to the OPFS panel. 

Ready.

What gets created

  • /hello.txt — small UTF-8 text
  • /sample.json — pretty JSON with nested structure
  • /image.png — 64×64 generated PNG
  • /data/notes.md — Markdown
  • /data/config.toml — TOML
  • /db/main.sqlite — file with SQLite magic header (placeholder)
  • /db/lockable.bin — locked on demand to test the lock badge
  • /nested/deep/path/leaf.log — to test tree depth and breadcrumbs
  • /large.bin — 5 MB random binary (only when you click "Add 5 MB blob")
  • /bw-chat.db.000, .001, .002 — real rsqlite-wasm DB split into 3 shards (chat-shaped schema)
  • /bw-chat.db — extra "stranded legacy" bare file (when you click "Add stranded legacy bare file")
